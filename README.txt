RLV GENERAL CONTRACTOR - FREE WEBSITE

1. Open index.html in your browser to preview the website.
2. Edit script.js and replace BUSINESS_EMAIL and BUSINESS_PHONE with the real business details.
3. Put your REAL project photos in the images folder, named:
   project-1.jpg, project-2.jpg, project-3.jpg
   (Use one image from each different project; never claim sample photos are real projects.)
4. Customize service details and project captions in index.html.
5. Create a free GitHub account. Create a public repository named YOURUSERNAME.github.io.
6. Upload index.html, style.css, script.js and the images folder to the repository root.
7. In Settings > Pages, select Deploy from a branch, main and / (root), then Save.
8. Visit https://YOURUSERNAME.github.io once deployment finishes.

NOTES:
- The estimate form uses mailto: and opens the visitor's email app. It does NOT send automatically.
- Contact buttons only appear after you enter real phone/email values.
- Google Fonts are loaded over the internet; the page still works without them.
- Free GitHub Pages does not provide server-side processing or a free custom domain.
- Do not put private or confidential data in the repository.
